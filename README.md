# Blood-Donation-Website 🚑💉

Overview 📚

A user-friendly web platform connecting blood donors and recipients efficiently, aiming to bridge the blood donation gap and save lives.

Features 🎉

- User registration and login system
- Donor and recipient profiles with essential information
- Blood donation request and offer system
- Search and filter functionality for easy matching
- Secure payment gateway for hassle-free donations

Technologies Used 💻

- Frontend: HTML, CSS, JavaScript, React , Bootstreap
- Backend: Node.js, Express.js
- Database: Firebase 🔥

Accepted by IEEE and Patent Pending 📜

This project has been accepted by IEEE and is currently in the process of being patented.
